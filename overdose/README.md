# Overdose - Tree Feller Data Pack (Java Edition 26.3)
**Author:** teamthee  
**Minecraft Version:** Java Edition 26.3 (*Wilderness Bound*)  

## คุณสมบัติใหม่ (Features)
1. **แสดงผลเฉพาะตอนถือขวาน (Axes Only):**
   - เมื่อถือขวานในมือ จะมีข้อความแจ้งเตือนที่ Actionbar ว่า `[Overdose] 🪓 Shift to activate`
   - เมื่อสลับไปถือไอเทมอื่น ข้อความและหลอดจะหายไป ไม่เกะกะสายตา

2. **กด Shift เพื่อชาร์จพลัง (Shift to activate):**
   - เมื่อถือขวานและกด Shift ปล่อย ย้ำๆ หลอดพลังงานจะเพิ่มขึ้นทีละ 20%
   - หลอดจะแสดงความคืบหน้าแบบเรียลไทม์: `⚡ [Overdose] [■■■■░░░░░░] 40%`

3. **เมื่อพลังงานเต็ม 100% (ACTIVE):**
   - หน้าจอจะขึ้นเตือน: `⚡ [Overdose] 🪓 ACTIVE! Chop to Fell Tree! [■■■■■■■■■■] 100% ⚡` พร้อมเสียงและออร่าประกายไฟ
   - **วิธีสั่งโค่นต้นไม้ (รองรับทั้ง 2 วิธี):**
     1. **ตัดท่อนไม้ (Left-Click Break):** ตัดไม้ท่อนใดก็ได้ ต้นไม้ทั้งต้นจะล้มลงมาทันที (รองรับโหมด Survival)
     2. **คลิกขวาที่ท่อนไม้ (Right-Click Axe):** สามารถคลิกขวาใส่ท่อนไม้เพื่อโค่นต้นไม้ได้ทันทีเช่นกัน (ใช้ได้ทั้ง Survival และ Creative Mode!)
   - กวาดล้างพื้นที่ 9x9 สูงถึง 37 บล็อก ล้มลงมาทั้งต้นตั้งแต่ตอไม้ยันยอดกิ่งไม้ในใบไม้

## วิธีติดตั้งและใช้งาน (Installation)
1. คัดลอกโฟลเดอร์ `overdose` นี้ไปวางไว้ในโฟลเดอร์ `datapacks` ของเซฟเกม:
   `.minecraft\saves\<ชื่อโลกของคุณ>\datapacks\`
2. พิมพ์คำสั่งในเกม:
   `/reload`
3. ถือขวานในมือ จะเห็นข้อความ `Shift to activate` ทันทีครับ!
